## 1. Phase B implementation

Phase B added only the read-only report data boundary:

```text
ReportService
└── ReportRepository
    └── Database
```

Implemented:

- immutable report DTOs in `core/models/report.py`;
- `ReportRepository.load_snapshot(project_id, report_type=PROJECT_SUMMARY)`;
- one SQLite connection, `PRAGMA query_only = ON` + explicit `BEGIN`;
- project-scoped queries for Project, Authorization, ScopeAsset, ScanTask,
  Finding and Evidence;
- DTO construction inside the read transaction;
- rollback and connection release in `finally`;
- `ReportService` statistics, authorization summary, data scope, warnings and
  known limitations;
- read-only evidence path/existence/SHA-256 checks;
- three report types: vulnerability, evidence, project summary.

Not implemented, by design:

- HTML, PDF or JSON rendering;
- report GUI;
- report table writes;
- database migration;
- remote scanning or network access.
